CCML — Stage 3.1: Inspector embedded-cover hotfix

Problem:
Inspector showed the music-note placeholder even when an MP3 contained embedded artwork.

Cause:
media.go accepted only pictures whose APIC role was exactly Front Cover.
Some valid MP3 files store their only artwork with APIC type Other (or another role).

Fix:
- prefer Front Cover when present
- otherwise use the first non-empty embedded image
- identify JPEG/PNG/GIF/WebP by payload signature before trusting MIME
- support cached GIF artwork
- add regression tests

This hotfix does NOT change:
- Inspector player controls
- loudnorm
- limiter
- audio processing
- spectrogram generation

5. Start:
