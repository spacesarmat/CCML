CCML — Stage 5.2 v2: Traxsource resilient search

Why v2:
The first installer expected one exact multiline formatting of TraxsourceProvider.
Your local traxsource.go differs from that formatting, so preflight stopped before
any file was changed.

v2 uses syntax-oriented regex anchors instead of exact multiline source text.
It also preserves the old one-argument NewTraxsourceProvider(userAgent) constructor
and adds NewTraxsourceProviderWithFallback(...), reducing compatibility risk.

Behavior:
- Direct Traxsource lookup remains first.
- No Cloudflare challenge emulation/cookie bypass is performed.
- If direct search is blocked or returns no useful results and a fallback key is
  configured, CCML queries the structured Traxsource JSON fallback.
- Without a key, a Cloudflare 403 becomes a compact actionable error.
- Optional API key is available in Settings -> Traxsource.
- Environment variable: TRAXSOURCE_API_KEY.
- If built-in Help exists, it is updated on a best-effort basis.

The current fallback search endpoint accepts:
  term=<artist title>
  type=tracks
  page=1
and authenticates with X-API-Key.
